01 研究問題

不是展示三張地圖。
是展示一次受控決策。

整體架構、SHP/OSM 工具、CRS、PMTiles、MapLibre 與驗證方法是既有基礎。這個 demo 聚焦檢驗：測圖知識能否控制 NMA 對使用者 Shapefile 的一次可授權、可執行、可驗證操作。

  1. 01
    理解使用者資料

    檢查 ZIP sidecars、CRS、geometry、欄位與識別碼，不偷換 open data。

  2. 02
    用規範形成提案

    重播 frozen Knowledge Graph / GraphRAG mapping rules，顯示選擇依據。

  3. 03
    人工授權後才執行

    提案與結果分離；BUILD production activation 始終 held。

  4. 04
    用 evidence 收尾

    feature count、ID、geometry、CRS、頂點與 provenance 可逐項檢查。

03 能力與限制

展示 knowledge-controlled execution，
不重複假裝整個 NMA 已在線。

本頁用 frozen NMA v1.0 規則做 deterministic retrieval replay，再對使用者 SHP 做瀏覽器內執行。它不是 live Agent、Neo4j 或 production GIS service。

既有
NMA architecture 與工具鏈

規範 → KG → GraphRAG → Agent → GIS tools → MapLibre/PMTiles，以及 SHP↔OSM、CRS、dissolve、ID preservation 等能力屬於研究基礎。

本頁
使用者 SHP 的受控 execution loop

輸入檢查、規則檢索、提案、人工授權、MapLibre 執行、QA 與 provenance。

未做
PMTiles / Hausdorff / OSM comparison

瀏覽器 demo 不假稱已執行；PMTiles 需 CLI/backend，Hausdorff 需使用者提供 reference geometry。

BUILD
Production activation held

允許 browser-local boundary/hatch preview；production writeback 永遠停用。
