你要繪製哪一種地理資料？

選擇與 Shapefile 幾何相符的工作。每一條路徑都會先檢查資料，再由 Agent 查找規範證據、提出計畫、等待授權、繪圖並觀察結果。

共同治理流程

不是把資料交給模型猜一張圖

三種幾何使用相同的控制點；差異只在資料 schema、分類知識與 portrayal tool。

  1. 1
    資料檢查元件、CRS、ID、schema、分類、geometry
  2. 2
    查找規範證據Knowledge Graph、GraphRAG、mapping rules
  3. 3
    人工授權授權綁定目前 plan；修訂後必須重審
  4. 4
    MapLibre 繪圖執行 geometry-specific portrayal tool
  5. 5
    觀察與決策verify、replan、abstain、request human 或 stop

目前能力邊界

可驗證的地圖預覽，不是 production activation

  • Fail closed缺少必要 Shapefile 元件、TERRAINID、CRS 或可用 ID 時，不建立 plan。
  • Read-only knowledgeAgent 只能使用受控知識查詢，不會自行修改正式 KG。
  • Observation-driven工具與 browser render 結果會回到 Agent decision；失敗可要求修訂或停止。
  • No data export本應用只驗證正確 portrayal，不產生下載資料，也不啟用正式製圖規則。
