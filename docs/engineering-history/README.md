# Engineering history

This is the canonical index for the project's milestone, audit, acceptance, and freeze reports.
The frozen reports remain at their original repository-root paths because historical manifests and
runtime verifiers bind those exact path strings and file hashes. Relocating them would be a
functional and reproducibility change, so the reconciliation indexes them instead. The newer Pages
deployment report, which is not part of `nma-v1.0-final`, is stored under `deploy/`.

These reports are engineering evidence. They do not validate the scientific hypotheses in RQ1–RQ3.
